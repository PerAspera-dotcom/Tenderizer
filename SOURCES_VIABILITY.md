## What changed vs. the CR's own preliminary hypotheses

- **UK**: confirmed green via FTS specifically (not MyTenders/MOD-specific portals), including defence coverage — matches the CR's own preferred path.
- **Canada**: confirmed green, exactly as hypothesized.
- **TenderNed**: confirmed green, exactly as hypothesized (CC0, not just "likely").
- **Australia**: the CR's "amber" guess undersold the problem — this is a real legal blocker on the exact data wanted (ATM material), not a wait-and-see. Marking red rather than amber so it doesn't quietly become a default "build it anyway, it's technically public" later.
- **Saudi**: better news than the CR's premise assumed — a real API program exists at `apiportal.etimad.sa`, not just a login-walled site. Still not confirmed to cover tender-listing data, so still amber, but the next step is "register and look at the product catalog," not "write off this market."
- **Singapore / Malaysia / Philippines**: stayed amber as hypothesized — none could be upgraded or downgraded with page-fetch-level evidence. Each needs either a real-browser probe (for the two that gave anti-bot signals) or a human reading the one PDF that wouldn't extract cleanly.

## Recommended build order (pending go-ahead)

1. **UK — Find a Tender Service** (`connectors/find_a_tender.py`) — public OCDS API, OGL-licensed, English (no translation step), includes MOD/defence. Lowest-risk build of the batch.
2. **Canada — CanadaBuys** (`connectors/canadabuys.py`) — daily CSV pull, OGL-licensed, English.
3. **TenderNed** (`connectors/tenderned.py`) — needs requesting API credentials from `functioneelbeheer@tenderned.nl` first (an email, not a code change) before this can go further than a dry-run against the public bulk datasets.

All three use **UNSPSC/GSIN-style or no classification codes** except TenderNed (CPV-native, EU standard — no mapping needed, same as BOAMP/TED). UK and Canada need the `source_code` + mapped-`cpv` approach the CR describes; where no mapping exists, keyword-only matching with a visible tag so the confidence model doesn't claim false CPV precision.

Everything marked amber above needs one more concrete step (an account/subscription signup, a PDF someone reads, or a real-browser probe past a WAF) before it's buildable — none of those are code-only follow-ups I can resolve from here.
